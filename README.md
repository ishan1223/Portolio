# Personal Portfolio

A premium, production-ready portfolio built with React, Vite, Tailwind CSS, and Framer Motion.

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## Customize

Edit `src/data/content.js` to update:

- Personal info (name, email, links)
- Skills, projects, experience
- Achievement statistics
- GitHub stats

Replace assets in `public/`:

- `public/resume.pdf` — your resume
- `public/images/portrait-placeholder.svg` — your professional photo
- `public/images/projects/` — project screenshots

## Build

```bash
npm run build
npm run preview
```

## Tech Stack

- React 19
- Vite 8
- Tailwind CSS 4
- Framer Motion
- React Icons
